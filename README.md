# Bias Auditor Project

This project investigates algorithmic bias in binary classification tasks using the Adult Income dataset. It explores fairness metrics, reweighting techniques, and comparisons across classifiers (Logistic Regression, Random Forest, Gradient Boosting).

## Structure
- `notebooks/`: EDA and model comparison
- `utils/`: Modular scripts for evaluation, plotting, fairness metrics etc.
- `outputs/`: Saved model predictions
- `results/`: Fairness Metrics, Initial model results etc.

## Status
Work in progress – model reweighting, fairness visualization complete. Currently experimenting with other bias mitigation techniques.
